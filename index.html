01 · Distributed Application

โปรแกรมประยุกต์ชนิดกระจาย

โปรแกรมประยุกต์ที่ทำงานร่วมกันผ่านอุปกรณ์คอมพิวเตอร์หลายเครื่อง โดยแต่ละเครื่องอาจรับผิดชอบงานคนละส่วน และเชื่อมต่อกันผ่านเครือข่ายเพื่อแลกเปลี่ยนข้อมูลและทำงานร่วมกัน

บทบาทหลัก

แบ่งงานทำงานร่วมกันบนหลายเครื่อง

โจทย์สำคัญ

ประสานงานเครือข่าย ความเสถียร และความสอดคล้องของข้อมูล

ลักษณะการทำงาน

  1. แบ่งหน้าที่การทำงานไปยังคอมพิวเตอร์หลายเครื่อง
  2. สามารถรับส่งข้อมูลผ่านเครือข่ายได้
  3. ช่วยกระจายภาระการทำงาน
  4. รองรับผู้ใช้งานหลายคนพร้อมกัน

ตัวอย่างโปรแกรม

  • Google Docs
  • Facebook
  • ระบบธนาคารออนไลน์
  • ระบบซื้อขายสินค้าออนไลน์

02 · Middleware

โปรแกรมตัวกลางเชื่อมต่อ

โปรแกรมที่ทำหน้าที่เป็นตัวกลางหรือสะพานเชื่อมระหว่างโปรแกรม ระบบ หรืออุปกรณ์ต่าง ๆ เพื่อให้สามารถติดต่อสื่อสาร แลกเปลี่ยนข้อมูล และทำงานร่วมกันได้

บทบาทหลัก

เป็นตัวกลาง/สะพานเชื่อมให้ระบบต่างกันคุยกันได้

โจทย์สำคัญ

ความเข้ากันได้ของข้อมูล การส่งต่อคำขอ และความปลอดภัย

ลักษณะการทำงาน

  1. เชื่อมต่อโปรแกรมที่แตกต่างกัน
  2. รับส่งและแปลงข้อมูลระหว่างระบบ
  3. ช่วยจัดการการสื่อสารระหว่างโปรแกรม
  4. เพิ่มความสะดวกในการพัฒนาระบบ

ตัวอย่างโปรแกรม

  • API Gateway
  • Web Server
  • Message Broker
  • Database Middleware

03 · Mobile Data Management

การจัดการข้อมูลในชุดอุปกรณ์เคลื่อนที่

การดูแลและจัดการข้อมูลที่อยู่ในอุปกรณ์เคลื่อนที่ เช่น โทรศัพท์มือถือและแท็บเล็ต ให้เป็นระเบียบ ปลอดภัย สามารถจัดเก็บ สำรองข้อมูล และเรียกใช้งานได้อย่างสะดวก

บทบาทหลัก

ดูแล เก็บ ซิงค์ และคุ้มครองข้อมูลบนมือถือ

โจทย์สำคัญ

การใช้งานออฟไลน์ การซิงค์ข้อมูล และความปลอดภัยเมื่อพกพา

ลักษณะการจัดการข้อมูล

  1. จัดเก็บและจัดหมวดหมู่ข้อมูล
  2. สำรองข้อมูลเพื่อป้องกันการสูญหาย
  3. ป้องกันข้อมูลด้วยรหัสผ่านหรือระบบสแกนลายนิ้วมือ
  4. ซิงก์ข้อมูลระหว่างอุปกรณ์
  5. ลบหรือกู้คืนข้อมูลเมื่อจำเป็น

ตัวอย่างโปรแกรม

  • Google Drive
  • iCloud
  • Google Photos
  • OneDrive
